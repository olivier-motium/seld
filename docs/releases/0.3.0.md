# Seld 0.3.0: the resident operations release

Seld 0.3.0 turns the ChatGPT desktop app into an AI chief of staff that can stay
current across the sources you choose. It keeps one local record of the people,
projects, commitments, decisions, and longer-running situations that shape your
work and life. Pulse reviews new evidence against that record, while Bridge
shows the few decisions that now need you.

## A Bridge built for daily use

Bridge has been rebuilt around five clear places:

- **Home** gives you the current brief and source coverage.
- **Rundown** presents one decision at a time, with the situation and proposed
  next move together.
- **Everything** keeps the complete Portfolio available without turning it into
  another board to maintain.
- **What Seld knows** makes saved context, people, projects, and source
  provenance inspectable.
- **System** shows health, recovery, and integration state.

The interface now uses the Seld design system from seld.ai, including the
product mark, local fonts, responsive layouts, high-contrast support, reduced
motion, and direct continuation into the exact ChatGPT task that owns the work.
If the underlying record changes while you are typing, Bridge keeps your draft,
reloads the current version, and asks you to review it before retrying.

## Onboarding starts with your life

`$gsv-onboard` begins with the context that makes Seld useful: what matters this
month, the shape of the current week, important people and projects, waiting
fors, constraints, and the boundaries Seld should respect. It reflects that
picture before asking you to connect apps.

You can then enable Gmail, Google Calendar and Drive, Outlook, Slack, Teams,
GitHub, Asana, Atlassian, Box, Figma, Notion, SharePoint, local files, Apple
Messages, WhatsApp, Shopify, Instagram, screen context, or another compatible
read-capable app or MCP tool. Provider-specific connection notes guide account
matching, bounded reads, and recovery. OAuth, account selection, consent, and
administrator approval stay in the provider's own flow.

Local files use separate host-local grants, so selecting the source grants
nothing by itself. After the user approves one exact directory, Seld reads only
a named relative path through `gsv_local_file_read`. The grant is tied to that
local record and directory, stays out of portable backups, and is revoked when
local files are deselected. Symlink escapes, protected paths, cloud
placeholders, and suspicious content are withheld.

After a read succeeds, Seld stores a content-free coverage record with hashed
account, host, tool, cursor, and evidence bindings. Raw provider bodies do not
become part of the local record. A missing tool, expired login, wrong account,
partial window, or stale read remains visible instead of being reported as
“nothing new.”

## Pulse keeps the model current

The resident Pulse is an AI-authored wake rather than a fixed rules engine. It
reads bounded changes from selected sources, interprets them in the context of
Direction and the complete Portfolio, and then updates the local record,
prepares a Rundown decision, continues one exact outcome, or stays quiet.

The deterministic layer handles storage integrity, privacy screens, bounded
inputs, compare-and-swap revisions, recovery, and replay prevention. The model
continues to decide what evidence means, whether two records describe the same
person, what deserves attention, and what should happen next.

Seld's MCP server exposes no provider-write, browser, screen-control, or
Computer Use tools. Pulse uses separately installed connector tools read-only
and never calls provider-write or Computer Use methods.

## Decisions survive the conversation

Bridge saves each choice once in an authenticated local queue. The CLI or MCP
processing path accepts or rejects the saved choice against the current record
versions. That result remains visible after restart, while stale writes,
duplicate delivery, and replay fail closed.

The guided Portfolio review uses the same boundary. It audits the complete open
set, brings forward only the outcomes that benefit from a decision, and keeps
checked coverage tied to the exact outcome and surrounding-situation versions
that were reviewed. An interrupted ChatGPT task returns as actionable recovery
state instead of a false completion or a duplicated run.

## Local, inspectable, and recoverable

Direction, Portfolio, Tasks, entities, WorkThreads, decisions, source coverage,
and current orientation remain readable Markdown on your Mac. Seld adds
verified backup and restore, crash recovery, conservative repair, reversible
ChatGPT integration, and an isolated demo that proves stale-write rejection and
fresh-process continuity without reading your real records.

Seld does not send messages, book appointments, make payments, change provider
data, or alter account access without your approval.

## State of the art for resident personal operations

Seld 0.3.0 is state of the art for resident personal operations because it
completes the whole operating loop in one product. Direction and Portfolio
establish what matters, source-aware reads keep the evidence current, Pulse
interprets changes in context, the Rundown turns them into a small set of useful
decisions, and exact task continuity carries those decisions across
conversations and restarts.

The whole-person model, source truth, selective attention, semantic continuity,
and approval-safe handoff all operate on the same local record. The
[architecture assessment](../state-of-the-art.md) documents the decision rule
and compares this implementation with current OpenClaw and Hermes Agent source
snapshots.

## Install or update

Seld 0.3.0 is built for the ChatGPT desktop app on macOS. Windows and Claude are
next.

```bash
uv tool install --force 'git+https://github.com/olivier-motium/seld.git'
gsv setup
```

The product is named Seld. The `gsv` command, package, plugin identifiers,
environment variables, and existing data paths remain unchanged so current
installations can upgrade in place.

Exact source-install, browser, package, privacy, and recovery evidence is
recorded in the [release ledger](../release-gates.md).

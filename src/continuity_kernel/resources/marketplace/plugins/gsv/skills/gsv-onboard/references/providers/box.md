# Box connection check

Use this note after Box is selected and its separately installed app tools are
available in a fresh ChatGPT task.

1. Ask for the expected Box account and enterprise or workspace context. Use a
   read-only user profile when available and require an exact account match.
2. Search or read a small recent file set within the approved scope. Avoid bulk
   listing and do not download content merely to verify access.
3. Do not upload, edit, move, share, comment on, delete, or change permissions
   during onboarding.
4. Missing tools get one new-task retry after enablement. Wrong account,
   enterprise policy, auth, or admin failures return to the Box-owned
   connection settings before another probe.
5. Return the identity and bounded-read result to `$gsv-onboard` for the
   content-free Seld receipt and exact CAS readback.

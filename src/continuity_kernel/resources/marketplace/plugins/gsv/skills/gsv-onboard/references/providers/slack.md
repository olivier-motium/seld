# Slack connection check

Use this note after Slack is selected and its app tools are available in a
fresh ChatGPT task. Slack owns workspace authorization and account selection.

1. Ask for the exact expected workspace and member account. Use a read-only
   auth or profile result to match both when available. A channel name or
   message author does not verify the connected account.
2. Read a small recent channel, thread, or direct-message window chosen with the
   person. Do not widen the read merely to prove access.
3. Do not send, draft, react, edit, delete, invite, change membership, or alter
   channel state during onboarding.
4. If tools are absent, enable the app and open one new task. Wrong workspace,
   auth, enterprise policy, or admin errors return to ChatGPT connection
   settings or the Slack administrator before one changed retry.
5. Return the identity and bounded-read facts to `$gsv-onboard` for the
   CAS-protected, content-free Seld receipt.
